# WISME APP - COMPREHENSIVE CODEBASE ANALYSIS

## Overview
Wisme is a Flutter-based microlearning application that provides personalized, AI-generated audio content for bite-sized learning sessions. The app uses OpenAI for content generation and ElevenLabs for text-to-speech conversion.

---

## MAIN ENTRY POINTS

### `lib/main.dart`
**Primary Application Entry Point**
- Initializes Flutter app with Firebase integration
- Sets up comprehensive provider ecosystem for state management
- Configures all core services: Auth, Firestore, GPT, TTS, Storage, Cache
- Creates provider tree for UserProvider, LessonProvider, AudioProvider, etc.
- Implements proper error handling for Firebase initialization
- Logs configuration status for deployment verification

### `lib/app.dart`
**Root Application Widget**
- Defines the main MaterialApp widget structure
- Integrates with SettingsProvider for theme management
- Sets up routing system and authentication flow
- Uses AuthWrapper for proper authentication handling

### Alternative Main Files:
- **`lib/main_basic_test.dart`** - Simple Flutter test without services
- **`lib/main_fixed.dart`** - Startup error handling with fallback UI
- **`lib/main_minimal.dart`** - Similar to main.dart but with reduced logging
- **`lib/main_simple.dart`** - Development testing with API status display
- **`lib/main_test.dart`** - Minimal test setup for basic Flutter functionality

## STATE MANAGEMENT (PROVIDERS)

### `lib/providers/user_provider.dart`
**User Authentication and Profile Management**
- Manages user authentication state with Firebase Auth integration
- Handles login, registration, logout operations
- Tracks onboarding completion status
- Converts between UserModel and UserProfile data structures
- Provides user preferences and profile data access
- Implements proper error handling and loading states

### `lib/providers/settings_provider.dart`
**Application Settings Management**
- Manages theme settings (light/dark mode, system preference)
- Handles app preferences: notifications, downloads, playback speed
- Learning preferences: daily goals, reminders, reminder times
- Persistent storage using SharedPreferences
- Provides settings validation and reset functionality

### `lib/providers/lesson_provider.dart`
**Content and Lesson Management**
- Core lesson generation and content management system
- Topic analysis and intent detection using GPT service
- Content block loading from cache and Firestore
- Search and filtering functionality for lessons
- Category-based content organization
- Integration with ContentMatchingService for personalized content
- Caching system for improved performance

### `lib/providers/audio_provider.dart`
**Audio Playback and Progress Management**
- AudioPlayer integration for content playback
- Progress tracking and session management
- Audio caching and offline playback support
- Playback speed control and position tracking
- Integration with Firestore for progress persistence
- Performance metrics and analytics tracking

### Additional Provider Files:

## ARCHITECTURE SUMMARY

### Key Architectural Patterns:
1. **Provider Pattern** - State management with separation of concerns
2. **Service Layer** - Business logic abstraction and API integration
3. **Repository Pattern** - Data access and caching management
4. **Clean Architecture** - Clear separation between UI, business logic, and data
5. **Component-Based UI** - Reusable, consistent design system

### Technology Stack:
- **Flutter** - Cross-platform mobile development
- **Firebase** - Authentication, database, and cloud services
- **OpenAI GPT-4** - AI content generation and analysis
- **ElevenLabs** - High-quality text-to-speech conversion
- **Provider** - State management and dependency injection
- **SharedPreferences** - Local data persistence
- **AudioPlayers** - Audio playback functionality

### Code Organization:
- **273 Dart files** total across the application
- **Modular structure** with clear separation of concerns
- **Comprehensive error handling** and graceful degradation
- **Production-ready configuration** with environment management
- **Extensive placeholder framework** for future feature development
