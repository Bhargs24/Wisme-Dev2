# Sample Audio File

This is a placeholder for episode 1 of Data Structures & Algorithms.

When you generate the actual audio using ElevenLabs Studio, place the MP3 files in this folder with names like:
- `maya_kai_dsa_episode_1.mp3` (main episode)
- `intro.mp3` (episode introduction)
- `summary.mp3` (episode summary)

The app will automatically detect and use these files when Firebase is unavailable.
