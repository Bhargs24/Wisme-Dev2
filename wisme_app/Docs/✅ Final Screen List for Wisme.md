✅ Final Screen List for Wisme
A complete, gap-free screen architecture — grouped by flow.
________________________________________
🔐 0. Authentication Flow
(Before onboarding or home dashboard)
Screen	Purpose
0.1 Splash / Welcome	App logo / animation → redirects to auth
0.2 Sign Up / Login	OAuth (Google, Apple), email, or Guest mode
0.3 Account Setup (Optional)	Username, T&Cs, optional preferences
________________________________________
🌀 1. First-Time Onboarding (Gamified + Guided)
(Only for new users or after guest upgrade to full account)
Screen	Purpose
1.1 Welcome to Wisme	“Learn anything in 10 minutes a day” intro
1.2 How Wisme Works (2–3 screens)	Swipeable overview: categories, coaches, short lessons
1.3 Why Are You Here?	Select intent: Upskill, curiosity, daily habit, etc.
1.4 What Are You Interested In?	Choose 1+ content categories (our 15 predefined ones)
________________________________________
🧠 2. Topic-Based Personalization Flow
(Triggered after onboarding or anytime user adds a new topic)
Screen	Purpose
2.1 Topic Entry	Open-ended prompt + smart suggestions (chips)
2.2 Category & Knowledge Level Detection	Behind-the-scenes AI categorization
2.3 Choose Your Learning Style	Dynamic options based on category (e.g. Fundamentals, Case Studies, Bit of Everything)
2.4 Choose Your Coach Personality	Kai 🧘 or Vee ⚡ — based on tone preference for this topic
2.5 Name Your Coach + Avatar	Personalize their identity per topic
________________________________________
🎯 3. Journey Launch
Screen	Purpose
3.1 Your Plan is Ready!	Title of journey (e.g. “5-Day Growth Hacking”), episode titles, progress bar
3.2 [Optional] Course Map	Full outline of episodes (mini-syllabus), expandable list
________________________________________
🎧 4. Daily Learning Flow
Screen	Purpose
4.1 Player Screen	Audio episode player (10–15 min), mood toggle (Kai ↔ Vee), TL;DR, daily action
4.2 Transcript View	Synchronized, scrollable text
4.3 Ask Coach a Question	AI Q&A with context awareness
4.4 After-Episode Feedback	“Was this helpful?” + optional text field
4.5 Suggested Next Episode	Continue, go deeper, or shift topic angle
________________________________________
🧭 5. Home / Dashboard Experience
Screen	Purpose
5.1 Home Dashboard	Continue learning, today’s plan, daily streak, “Feeling Curious?”
5.2 Coaches	See all active coaches (per topic), switch between them
5.3 Library	Saved/favorited episodes, completed topics
5.4 Course Inbox	Coach messages, summaries, suggestions to deepen
5.5 Mood Toggle	Set default coach tone (Kai/Vee), applies globally unless overridden per topic
________________________________________
🔍 6. Search & Reuse Flow
Screen	Purpose
6.1 Smart Search	Search for topics → runs reuse algorithm based on hashtags, topic match, level
6.2 Tailored Journey Result	Shows reused content and new generated episodes mixed into a course map
6.3 Episode Detail	View summary, tags, metadata (title, coach, length, level, etc.)
________________________________________
⚙️ 7. Settings & Profile
Screen	Purpose
7.1 Profile & Preferences	Avatar, name, email, default mood
7.2 App Settings	Playback speed, notifications, theme
7.3 Account & Privacy	Log out, delete account, export data
7.4 Upgrade / Subscription	(If freemium) Plan management, billing, etc.
________________________________________
💬 8. Miscellaneous & Utility
Screen	Purpose
8.1 Error / Offline	Network issues, retry interface
8.2 Empty States	When no topics exist yet, no saved content
8.3 Onboarding Reminder	For guests → prompt to create account to save progress
8.4 Rate the App / Feedback	Light prompt after 3–5 sessions
________________________________________
🧠 Optional But Valuable (Future Enhancements)
●	Daily Recap Email/Notification UI → “Here’s what you learned today…”

●	Coach Gallery / Mood Marketplace (if more personalities added)

●	Mini Topic Builder → “Help me create a path” using templates or AI
